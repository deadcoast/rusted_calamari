# Rusted Calamari v0.3.0

Windows x64 portable release of the two-tree image workspace, with the
supplied Rusted Calamari logo embedded in the executable and all app windows.

## Download and run

Download `rusted-calamari-0.3.0-x86_64-pc-windows-msvc.zip`, extract it and run
`rusted-calamari.exe`. No installer or Rust toolchain is required. The matching
`.zip.sha256` file contains the archive's SHA-256 checksum.

Open a folder with `Ctrl+O` or drop it onto the window. Hover the top/bottom
edges for controls, press `H` for help, or `.` for Settings. Sorting keys move
real files into category folders; `Ctrl+Z` undoes within the library session.

## Included

- Favourites above and a full-filesystem Files browser below, both using OTF.
- Native floating tree windows, dock snap-back, remembered placement, and
  gated triple-click recall/restore with image-focused folding.
- Files Anchor: off follows app folder changes; on keeps its independent path.
- The supplied transparent logo as a 16–256px Windows icon and shared runtime
  icon, plus executable version metadata.
- Rewritten user documentation, a repeatable packaging script, build metadata,
  original logo assets, font licence and dependency notices.

## Verification

All 46 tests, strict Clippy, formatting and the explicit Windows x64 release
build pass. Native workspace smoke passes. The extracted portable executable
passes checks for architecture, GUI subsystem, version information, all nine
embedded icon payloads, native window/icon creation and normal exit using an
isolated profile. Archive and executable checksums are verified before upload.

Physical mouse gestures, mixed-DPI/multi-monitor behaviour and Explorer/taskbar
icon-cache appearance on other machines remain outside this verification.
See [release verification](https://github.com/deadcoast/rusted_calamari/blob/v0.3.0/docs/verification/release-v0.3.0.md)
for the exact evidence boundary.
